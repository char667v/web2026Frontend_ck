      📚 PDF 01 — JavaScript & TypeScript NOTER

      • SLIDE 3 — WHAT IS JAVASCRIPT?

        JavaScript er et programmeringssprog til nettet og er en af de tre kerneteknologier sammen med HTML (struktur) og CSS (design). Det kører direkte i brugerens browser uden en server og gør websites interaktive — brugere kan klikke knapper, sende formularer og hente data fra servere via APIs uden at reloade siden.

        Til eksamen: Hvad er JavaScript? Et programmeringssprog der kører i browseren og gør websites interaktive.

      • SLIDE 4 — WHAT IS TYPESCRIPT?

        TypeScript er et superset af JavaScript — al JavaScript er gyldig TypeScript. TypeScript tilføjer statiske typer så vi angiver hvad slags data en variabel kan indeholde (number, string, boolean). Det hjælper med at fange fejl tidligt under kodning i stedet for når koden kører. Browsere forstår ikke TypeScript direkte — det skal kompileres til JavaScript med kommandoen tsc -p .

        Til eksamen: Hvad er forskellen på TypeScript og JavaScript? TypeScript tilføjer typer og fanger fejl tidligt. TypeScript skal kompileres til JavaScript før browseren kan køre det.

      • SLIDE 5-6 — BASICS & DATA TYPES

        De grundlæggende koncepter er: variabler, data typer, functions, classes, objects og arrays. Grundlæggende TypeScript typer: string (tekst), number (tal), boolean (true/false), number[] (array af tal), string[] (array af strings), void (funktion returnerer ingenting), Date (dato objekt). Optional parameter markeres med ?: fx birthdate?: Date betyder parameteren ikke er påkrævet.

        Til eksamen: Hvad er void? Void bruges som returtype når en funktion ikke returnerer noget. Hvad er en optional parameter? En parameter markeret med ? der ikke er påkrævet når funktionen kaldes.

      • SLIDE 7-8 — TRANSPILE TS TO JS / TSCONFIG

        TypeScript kompileres til JavaScript med tsc -p . som læser tsconfig.json i projektets rod. tsc -w -p . lytter efter ændringer og kompilerer automatisk. tsconfig.json konfigurerer projektet: rootDir: "./src" angiver hvor .ts filer ligger og outDir: "./dist" angiver hvor kompilerede .js filer gemmes.

        {
  "compilerOptions": {
    "rootDir": "./src",
    "outDir": "./dist"
  }
}

        Til eksamen: Hvad gør tsc -p .? Den kompilerer alle TypeScript filer til JavaScript baseret på tsconfig.json.

      • SLIDE 9 — VARIABLER: var, let, const

        var er den gamle måde at deklarere variabler — den har function scope og kan redeclareres. Brug den aldrig i moderne kode. let bruges til variabler der kan ændres — de har block scope. const bruges til konstanter der ikke kan ændres efter oprettelse. Brug const som default og skift til let hvis du har brug for at ændre værdien.

        var name2 = "Christian";   // undgå dette
let name3 = "Mai";         // kan ændres: name3 = "Anna"
const name4 = "Sophie";   // kan ikke ændres

        Til eksamen: Hvad er forskellen på var, let og const? var har function scope og kan redeclareres. let og const har block scope. const kan ikke reassignes efter oprettelse.

      • SLIDE 10 — FUNCTIONS

        En funktion er genanvendelig kode der kan tage parametre som input og returnere en værdi som output. I TypeScript angiver vi typer på parametre og returværdi. Der er to syntakser:

        // Declaration syntax
function add(a: number, b: number): number {
    return a + b;
}

// Arrow function syntax
const add = (a: number, b: number): number => a + b;

        Til eksamen: Hvad er en funktion? Genanvendelig kode der kan tage input og returnere output. Hvad betyder return? Return sender en værdi tilbage til der hvor funktionen blev kaldt.

      • SLIDE 11-13 — OBJECTS & DESTRUCTURING

        Et objekt oprettes med krøllede parenteser og kan have properties og metoder. Man kan tilføje nye properties efterfølgende. Nested objects er objekter inde i objekter. Destructuring udtrækker properties fra et objekt til separate variabler i én linje.

        let person = { firstname: "Peter", lastname: "Hansen" };
person.age = 30;                          // tilføj property
person.address = { city: "New York" };    // nested object
console.log(person.address.city);

const { firstname, lastname } = person;   // destructuring

        Til eksamen: Hvad er destructuring? En måde at udtrække properties fra et objekt til separate variabler i én linje.

      • SLIDE 15-17 — CLASSES & CONSTRUCTOR

        En klasse er en blueprint til at oprette objekter med samme struktur men forskellige værdier. constructor() køres automatisk når man opretter et objekt med new ClassName(). Metoder er funktioner der tilhører klassen og har adgang til classens properties via this — this refererer altid til det aktuelle objekt.

        class Cat {
    catname: string;
    constructor(name: string) {
        this.catname = name;
    }
    getCatname(): string {
        return this.catname;
    }
    setCatname(newName: string): void {
        this.catname = newName;
    }
}
let myCat = new Cat("Whiskers");
console.log(myCat.getCatname()); // "Whiskers"

        Til eksamen: Hvad er en klasse? En blueprint til objekter. Hvad er en constructor? En metode der opretter et objekt og køres automatisk ved new ClassName(). Hvad er this? this refererer til det aktuelle objekt.

      • SLIDE 18 — EXERCISE: CLASS (CAT)

        Cat klassen har name, color og breed properties. Constructor tager 3 parametre. getCatname() returnerer kattens navn. setCatname() ændrer kattens navn. To instanser oprettes og metoder testes med console.log.

      • SLIDE 19 — EXERCISE: CAR

        Car klassen har make, model, year, color, series og isRunning properties. getCarInfo() returnerer en string med bilens info. start() sætter isRunning til true. stop() sætter isRunning til false. To instanser oprettes og alle metoder testes.

        class Car {
    isRunning: boolean = false;
    constructor(public make: string, public model: string, public year: number) {}

    getCarInfo(): string { return `${this.make} ${this.model} ${this.year}`; }
    start(): string { this.isRunning = true; return `${this.make} has started`; }
    stop(): string  { this.isRunning = false; return `${this.make} has stopped`; }
}

      • SLIDE 20-22 — ARRAYS

        Et array er en ordnet liste af elementer. I TypeScript angives typen med []: number[] er et array af tal. Vigtige metoder: push() tilføjer et element til slutningen og ændrer det originale array. indexOf() returnerer index af et element — returnerer -1 hvis ikke fundet. slice(start, end) returnerer en del af arrayet som et nyt array uden at ændre originalen. Et array kan også indeholde objekter.

        let names: string[] = ["Anna", "Peter", "Maria"];
names.push("Lars");              // tilføj element
names.indexOf("Peter");          // returnerer 1
names.indexOf("Lars");           // returnerer -1 hvis ikke fundet
names.slice(0, 3);               // returnerer de første 3

let people = [];
people.push({ firstname: "Christian", email: "kirs@cphbusiness.dk" });
console.log(people[0].email);    // henter første persons email

        Til eksamen: Hvad returnerer indexOf() hvis elementet ikke findes? -1. Hvad er forskellen på push() og slice()? push() ændrer det originale array. slice() returnerer et nyt array uden at ændre originalen.

      • SLIDE 23 — EXERCISE: ARRAYS & OBJECTS (STUDENT)

        Student klassen har name, id og grades som et number array. addGrade() tilføjer en karakter til grades arrayet med push(). updateStudentName() opdaterer navnet. Et student objekt oprettes, grades tilføjes og navnet opdateres.

        class Student {
    grades: number[] = [];
    constructor(public name: string, public id: number) {}

    addGrade(grade: number): void { this.grades.push(grade); }
    updateStudentName(newName: string): void { this.name = newName; }
}

const student1 = new Student("Anna", 1);
student1.addGrade(7);
student1.updateStudentName("Anna Jensen");
console.log(student1);
